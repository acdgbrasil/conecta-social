# Organizational Blueprint — Conecta Social

Este diretório serve como molde para replicar a organização do `conecta-social` em outros monorepos multi linguagem. Cada arquivo aprofunda uma dimensão específica:

1. `01-monorepo-governance.md` — raiz, workspaces, convenções de pastas e como mesclar runtimes diferentes.
2. `02-handbook-and-knowledge.md` — como o handbook mantém contexto compartilhado (domínio, processos, qualidade).
3. `03-domain-and-testing.md` — estratégia DDD, uso dos pacotes `shared/*` e filosofia RED/Green para testes.
4. `04-multilanguage-playbook.md` — passos para hospedar múltiplas linguagens, toolchains e políticas de interoperabilidade.
5. `05-operational-checklist.md` — checklist rápido para bootstrapar um projeto espelhado (infra + rituals).

> Use estes arquivos como um "kit de clonagem". Cada seção referencia caminhos reais do repositório atual para facilitar a adaptação.
